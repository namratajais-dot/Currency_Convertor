💱 Currency Converter

🗓️ Date: January 2025
🧠 Tech Stack: React.js, TailwindCSS, REST APIs

🚀 Overview
A responsive React.js web application for real-time currency exchange and conversion, designed with TailwindCSS for a modern and clean interface.

⚙️ Features
🌍 Real-Time Conversion: Fetches live exchange rates from a public REST API, updating automatically every 30 seconds.
💸 Supports 50+ Currencies: Converts between major global currencies with accurate and up-to-date rates.
⚡ Dynamic UI Updates: Instantly reflects changes in selected currencies and amounts.
📱 Responsive Design: Optimized with TailwindCSS for seamless performance across all screen sizes and devices.
🔄 Auto Refresh: Keeps exchange rates current without manual reloads.
